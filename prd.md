This is the website containing all information regarding Forró events in Berlin. It hosts basic information about the dance, an FAQ, and links to classes, weekly socials, and other events, all promoted by local organizers. It interfaces with other applications (ex: filora, pretix) in order to render tickets sales and calendar when appropriate.
